# 练习算法

|  | 题目 | 说明 |
|------|------|------|
| 1 | 两数之和 | 暴力枚举，双循环查找 |
| 2 | 移动零 | 双指针，将非零元素前移 |
| 3 | 相交链表 | 双指针遍历，消除长度差 |
| 4 | 反转链表 | 三指针迭代，逐个翻转 |
| 5 | 回文链表 | 值存入数组，双指针对比 |
| 6 | 环形链表 | 快慢指针，相遇则成环 |
| 7 | 合并两个有序链表 | 递归，逐个比较头节点 |
| 8 | 二叉树的中序遍历 | 递归，左-根-右 |
| 9 | 二叉树的最大深度 | 递归，取左右子树最大值加一 |
| 10 | 二叉树的最小深度 | 递归，区分单子树与双子树情况 |
| 11 | 二叉树的翻转 | 递归，交换左右子树 |
| 12 | 对称二叉树 | 双向遍历，左子树左序与右子树右序对比 |
| 13 | 二叉树的直径 | 递归求深度，记录经过节点的最大路径长度 |
| 14 | 有序数组转换为二叉搜索树 | 取中点作为根，递归构造左右子树 |
| 15 | 搜索插入位置 | 二分查找，返回应插入的下标 |
| 16 | 有效的括号 | 栈匹配，左括号入栈右括号出栈对比 |
| 17 | 买卖股票的最佳时机 | 记录历史最低价，求最大差值 |
| 18 | 爬楼梯 | 斐波那契数列，迭代求和 |
| 19 | 杨辉三角 | 逐行构造，首尾为1，中间为上一行相邻两数之和 |
| 20 | 只出现一次的数字 | 异或运算，相同数异或为0 |
| 21 | 多数元素 | 哈希表计数，找出现次数超过一半的数 |
| 22 | 最长连续序列 | 排序后遍历，去重并记录最长连续段长度 |
| 23 | 盛最多水的容器 | 双指针，从两端向中间收缩求最大面积 |
| 24 | 三数之和 | 排序后固定一个数，双指针找剩余两数 |
| 25 | 找出字符串中所有字母异位词 | 滑动窗口，比较字符频次数组 |
| 26 | 和为K的子数组 | 前缀和加哈希表，记录前缀和出现次数 |
| 27 | 最大子序和 | 动态规划，记录当前前缀和与最大值 |
| 28 | 合并区间 | 排序后遍历，重叠则合并右边界 |
| 29 | 旋转数组 | 取模后截取后k个元素拼接到前面 |
| 30 | 除自身以外数组的乘积 | 左右前缀积，分别从两端遍历相乘 |
| 31 | 矩阵置零 | 用首行首列标记，原地修改矩阵 |
| 32 | 螺旋矩阵 | 四边界逐层收缩，顺时针遍历 |
| 33 | 旋转图像 | 先转置矩阵，再每行翻转 |
| 34 | 搜索二维矩阵 | 从左下角开始，大于目标上移，小于目标右移 |
| 35 | 两数相加 | 虚拟头节点，进位相加 |
| 36 | 删除链表的倒数第N个节点 | 虚拟头节点，快慢指针，快指针先走n步再同步移动 |
| 37 | 验证二叉搜索树 | 中序遍历，记录前驱节点值，当前值须大于前驱 |
